# CPH Railmotor – Derail Valley

Welcome to the resource repository for my YouTube tutorial series:

**Learn With Me – Create Custom Trains in Derail Valley!**

In this series, we're learning how to build a custom NSWGR CPH Railmotor for Derail Valley using Unity, Custom Car Loader (CCL), and eventually Blender.

This is a learning experience, not a step-by-step guide from an expert. I'm discovering how things work as we go, sharing both the successes and the mistakes along the way!

## 📁 Available Resources

This repository contains downloadable resources used throughout the tutorial series.

### Graphics

- **Speedometer graphic** – Used to create the CPH Railmotor's speedometer.

### Audio

- Diesel engine sound effects.
- Engine starter sound effects.

Additional resources will be added as the series progresses.

## 📥 Downloading the Resources

To download everything:

1. Click the green **Code** button at the top of this repository.
2. Select **Download ZIP**.
3. Extract the ZIP file to a folder on your computer.

You can also browse the folders and download individual files.

## 🚂 About the Project

The aim is to create a functional railmotor inspired by the New South Wales Government Railways (NSWGR) CPH class, affectionately known as the **"Tin Hare."**

We're starting with a basic working vehicle and gradually adding driving controls, instruments, sound effects, and eventually a custom 3D model.

The project is being developed for the railway simulation game **Derail Valley**.
